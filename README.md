# Walima Reception — Arshad & Rizwaana

Digital invitation card for the Walima Reception of Arshad & Rizwaana, scheduled for Sunday, 3 January 2027 at Natural Greenz Lawn, Nagpur.

## Features
- **Semantic HTML5** & accessible landmarks (`main`, `article`, `time`, `dl`).
- **Zero Dependencies**: Pure HTML and CSS with vanilla styling.
- **Responsive Layout**: Designed for high-DPI mobile devices and desktops alike.
- **Social Media Ready**: Open Graph and Twitter Card tags with pre-rendered 1200x630 social preview image.
- **Cloudflare Pages Optimized**: Includes `_headers` (security headers, asset caching) and `_redirects`.

## Deployment on Cloudflare Pages
1. In Cloudflare Dashboard, navigate to **Compute (Workers) > Pages**.
2. Click **Connect to Git** and choose this repository (`walima-reception` or `walima-page`).
3. Build Settings:
   - **Framework preset**: None
   - **Build command**: *(leave blank)*
   - **Build output directory**: `/` (root)
4. Click **Save and Deploy**.
